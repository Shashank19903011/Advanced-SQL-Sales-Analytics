# Advanced-SQL-Sales-Analytics
Advanced SQL Sales Analytics using SQL Server, CTEs, window functions, ranking, growth analysis, and business insights.

## 📌 Project Overview

This project demonstrates practical SQL Server skills using a sales and orders dataset.

The objective is to analyze sales, profit, customers, products, categories, regions, and order performance using SQL queries designed around real-world business scenarios.

The project contains 50 SQL interview-style questions covering basic SQL, aggregations, date analysis, window functions, CTEs, subqueries, ranking, profitability analysis, and data-quality checks.
